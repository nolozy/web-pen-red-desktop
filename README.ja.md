# Web Pen - Red（デスクトップ版）

**日本語** | [English](README.md)

Windows の**画面全体**に、赤いペンで直接描き込むアプリです。リプレイ、ゲーム、スライド、ビデオ通話の上に描けます。[Chrome 拡張機能](https://github.com/nolozy/web-pen-red)と同じ小さなツールバー（**132 × 36 px**）が、すべてのディスプレイの上に出ます。

ボタンは **ペン / カーソル / 全消去 / 終了** の4つだけです。色選択の画面はなく、ペンモード中に **R / Y / G / B / W** のキーで、赤・黄・緑・青・白に切り替えます。

## しくみ

- 透明で最前面の描画用ウィンドウが、**すべてのディスプレイ**に重なります。描いているときだけ存在します。
- **ペンモード**: 描画用ウィンドウがマウスとキーボードを受け取り、描けます。
- **カーソルモード**: 描画用ウィンドウは完全に素通しになります。描いた線は残り、下のアプリ（リプレイ、ゲーム、ブラウザ）は普段どおり操作でき、キーボードも戻ります。
- ツールバーは、下のアプリからキーボードの操作を奪いません。

## 起動のしかた

| 方法 | 動作 |
| --- | --- |
| アプリを起動する / タスクバーや通知領域のアイコンをクリック | すぐにペンが使える状態で開く（ペンモード・赤） |
| **Ctrl + Shift + P** | 非表示 → 表示（ペン）／カーソルモード → ペンに戻る／ペンモード → 非表示 |
| もう一度起動する（タスクバーにピン留めしたアイコン） | Ctrl + Shift + P と同じ。2つ目は起動しません |

タスクバーにピン留めすると、1クリックで起動できます。終了は、通知領域のアイコンを右クリックして選びます。

## 機能

| ボタン | 動作 |
| --- | --- |
| ✏️ ペン | ペンモード ON。ドラッグで線を描画（既定は赤） |
| ➤ カーソル | ペンモード OFF。すべて素通しになり、描いた線は残る |
| 🗑 全消去 | すべてのディスプレイの線を消去 |
| ✕ 終了 | すべての線を消して描画画面を隠す（アプリは通知領域に残る） |

ツールバーはドラッグで好きな位置に動かせます（ボタンの上からドラッグしても誤作動しません）。

### ショートカット（ペンモード中）

| キー | 動作 |
| --- | --- |
| **Tab** | ペン ⇄ カーソル |
| **R / Y / G / B / W** | 赤 `#FF0000` / 黄 `#FFD500` / 緑 `#00C853` / 青 `#2979FF` / 白 `#FFFFFF` |
| **右クリック** | すべてのディスプレイの線を即座に全消去（確認なし） |
| **Ctrl + Shift + P** | 上の表のとおり |

- これらのキーは、ほかのアプリの邪魔にならないよう、ペンモード中だけ効きます。カーソルモードから描き直すときは、**Ctrl + Shift + P** かツールバーのペンボタンを使います。
- 色を切り替えても、すでに描いた線の色は変わりません。
- 白は暗い場面用です。白い背景では見えません。

## 導入

### ダウンロード（ビルド不要）

[Releases](https://github.com/nolozy/web-pen-red-desktop/releases) に公開されたときは、`Web Pen - Red 1.0.0.exe`（ポータブル版、ダブルクリックで起動）か `Web Pen - Red Setup 1.0.0.exe`（インストーラー）を入手してください。コード署名をしていないため、Windows の SmartScreen が警告を出すことがあります。**詳細情報 → 実行** を選んでください。

### 自分でビルドする

```bash
git clone https://github.com/nolozy/web-pen-red-desktop.git
cd web-pen-red-desktop
npm install
npm start          # 起動
npm run dist       # インストーラーとポータブル版を dist/ に作る
```

Node.js が必要です。Electron と、素の HTML / CSS / JavaScript で作っています（フレームワークなし）。

## 知っておいてほしいこと

- **ゲーム・リプレイ**（例: League of Legends のリプレイ）: ゲームの画面モードは **ボーダーレス** か **ウィンドウ** にしてください。本物の（排他的）フルスクリーンでは、Windows が他のウィンドウを重ねて表示しません。このアプリは、画面の上に自分のウィンドウを重ねるだけで、ゲームには何もしません。ゲームの規約は、ご自身で確認してください。
- **画面共有**: **画面全体**を共有しているときは、描いた線が相手にも見えます。**ウィンドウ単体**を共有しているときは、線が別のウィンドウに描かれるため、相手には見えません。
- **Ctrl + Shift + P** は、一部のアプリ（VS Code のコマンドパレット、Firefox・Edge のプライベートウィンドウ）でも使われています。このアプリの起動中は、ペンが優先されます。ほかのアプリが先に使っている場合は、通知を出すので、通知領域のアイコンから操作できます。
- 線は、描いたディスプレイに属します。ディスプレイを抜き差しすると、線は消えます。
- 今は Windows のみです。

## ファイル構成

```
main.js              Electron のメイン処理（ディスプレイごとの描画画面、ツールバー、常駐アイコン、ショートカット、モード）
preload-overlay.js   描画画面との橋渡し
preload-toolbar.js   ツールバーとの橋渡し
renderer/            描画画面（canvas）、ツールバー（132x36px、拡張機能と同じデザイン）
assets/              アイコン（アプリ、常駐アイコン）
```

## スコープ

拡張機能と同じく、意図的に最小限です。ペン、カーソル、全消去、終了、キーボードで切り替える5色だけです。線の太さ、図形、保存、共有はありません。
